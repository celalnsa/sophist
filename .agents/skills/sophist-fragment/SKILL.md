# Sophist Fragment

Use this for短句：一两句、两三行、一小段突然想到的话。它不是短微博，不是诗歌练习，也不是格言工厂。

For evaluation or repeated iteration, read:

- `../_sophist-writing/standards.md`
- `../_sophist-writing/evaluation.md`

## Core Standard

A fragment should feel found, not manufactured. It should carry one thought and
leave some silence around it.

## Workflow

1. **Find one thought**: if input has multiple thoughts, split them into
   multiple fragments.
2. **Find the pressure point**: contradiction, concrete image, question, or
   plain judgment.
3. **Preserve the strongest original phrase** if it has personality.
4. **Cut to 1-4 lines**. Do not explain after the line lands.
5. **Prefer the plain version**: if one variant sounds quotable and another
   sounds like something the user would actually write down, keep the latter.
6. **Return variants when useful**: 3-6 options, labeled by difference such as
   colder, warmer, sharper, more colloquial.
7. **Evaluate**: use the fragment section in `evaluation.md`; optionally run
   `../_sophist-writing/scripts/evaluate_sophist_article.py --genre fragment`.

## Patterns That Fit

These are recognition patterns, not generation templates. If a short line has
symmetry, abstract noun pairs, or a pretty turn, first try a clumsier, more
private version. In every set of variants, keep at least one version close to
the user's raw sentence.

- Image then judgment: "辣是热，再加上痛。"
- Contradiction: "讨厌被控制，向往自由，同时又害怕自由。"
- Plain observation: "社交是一种技能，需要消耗能量。"
- Tiny future scene: "儿子，你认为香肠就该用面粉做吗？"

## Quality Gate

- One thought only.
- At least one concrete word, image, or pressure point.
- No quote-poster polish.
- No explanatory tail.
- If it sounds too balanced, break it or cut it.
- It can be awkward, even a little private. Do not sand it into a public slogan.

## Avoid

- "愿你", "愿我们", "人生就是", "世界终会".
- Stock profundity: 宇宙、星辰、命运、时代 unless the user's fragment truly has it.
- Symmetrical aphorisms that could be generated by any model.
- Expanding the fragment into a small essay without being asked.
